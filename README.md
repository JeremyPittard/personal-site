# Personal Site

[![Netlify Status](https://api.netlify.com/api/v1/badges/a309744c-cec7-4b56-8b38-410bc784fcab/deploy-status)](https://app.netlify.com/sites/jpittard/deploys)

This site is built with [Astro](https://astro.build). It’s a space for my portfolio, blog, and whatever else I feel like sharing. Think of it as my digital playground.

## 🌟 Features

- **Blog**: Paginated thoughts and articles, all pulled from Notion because I didn’t want to deal with another CMS.
- **Custom Components**: Modular and reusable, because why not?
- **Font Settings**: Toggle between fonts designed for accessibility and readability on blog posts.
- **Fast Performance**: Thanks to Astro’s static generation, this site is snappy.

## 🚀 Project Structure

Here’s how things are organized:

```text
/
├── public/              # Static assets like favicon and fonts
├── src/
│   ├── assets/          # Images and other media
│   ├── components/      # Reusable UI components
│   ├── content/         # Blog and site content
│   ├── icons/           # icons for astro-icon
│   ├── layouts/         # Layout templates
│   ├── pages/           # Site pages
│   ├── styles/          # CSS styles
└── package.json         # Project dependencies and scripts
```

## 🛠️ Development

Want to poke around or make your own version? Here’s how:

1. Clone the repository:

   ```sh
   git clone <repository-url>
   cd personal-site
   ```

2. Install dependencies:

   ```sh
   npm install
   ```

3. Start the development server:

   ```sh
   npm run dev
   ```

   The site will be available at `http://localhost:4321`.

## 📦 Deployment

This site is deployed using [Netlify](https://www.netlify.com/). If you want to deploy your own version, you’ve got options:

Deploy to Netlify, Vercel, Cloudflare or a similar service where they do all the heavy lifting for you

OR

1. Build the site:

   ```sh
   npm run build
   ```

2. Deploy the `dist/` folder to your hosting provider. Or just let Netlify/Vercel/Cloudflare handle it for you.
